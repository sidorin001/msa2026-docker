Среда выполнения: GitHub Actions, Ubuntu 24.04, Docker Engine 28.0.4, Docker Compose 2.38.2, Python 3.12, Playwright 1.56.0 / Chromium. Для браузера явно установлена локаль `en-US`: локаль POSIX тестового runner не является допустимым тегом Intl для интерфейса pgAdmin 9.8.

| Проверка | Результат |
|---|---|
| `docker compose config --quiet` | Успех |
| `docker compose build` | Оба C++17/CMake-сервиса собраны; SHA-256 зависимостей подтверждены |
| `caddy validate` | Конфигурация валидна |
| `docker compose up -d --wait --wait-timeout 180` | Запущены все шесть компонентов |
| `python tests/smoke.py` (вызывается из integration) | Точные данные 4/10, распределение 2/3/5/0, все маршруты и записи, фильтр и агрегирование |
| Ошибки и валидация API | 400/404/405, переполнение ID, пустая группа, неизвестные/старые маршруты, HEAD |
| Права PostgreSQL | SELECT разрешён; INSERT/UPDATE/DELETE/CREATE запрещены; нет SUPERUSER/TEMP и CONNECT к postgres/template1 |
| Топология и runtime | Только один опубликованный порт; сети разделены; чужая БД недоступна из API-контейнера; непривилегированный UID, нет g++/CMake |

| `python tests/pgadmin_browser.py` | Вход через /pgadmin/, JS/CSS без ошибок, оба сервера подключены, получено подтверждение подключения к groups_db и items_db |
| Проверка файлов | `git diff --check` без ошибок; .env и .local не отслеживаются Git |

Снимки `groups_db.png`, `items_db.png`, `pgadmin-final.png` доступны в артефакте **browser-results** указанного запуска Actions до истечения срока хранения. Пароли в CI случайные; тестовое окружение и его volumes удалены после проверки.

Локальная среда подготовки: Windows, Docker/CMake/компилятор C++ не установлены. Запуск на этом компьютере, Docker Desktop/WSL, ARM-архитектура, другие браузеры и нагрузочные сценарии не проверялись. Побитная воспроизводимость apt-пакетов не заявляется. Запуск проверен на указанном Linux runner; дальнейшие изменения версий требуют повторного CI.
