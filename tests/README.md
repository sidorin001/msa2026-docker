# Проверки

`python tests/smoke.py --base-url http://localhost:8080` — только чтение, Python 3 stdlib. Проверяет точные seed-данные, все записи и списки, агрегирование, фильтр, пустую группу, ошибки, неверные ID, методы и внешние маршруты. Ожидает готовность до 120 секунд, возвращает ненулевой код при провале.

`python tests/integration.py` — **только для отдельного одноразового стенда** на порту 8080. Останавливает компоненты, выполняет заведомо запрещённые SQL-команды от app-роли, пересоздаёт контейнеры через `down`/`up` без удаления volumes. Проверяет сетевую конфигурацию, отсутствие опубликованных портов и компилятора в runtime, UID, отказ и восстановление БД/Service2, отсутствие дублей seed и сохранность данных. Не запускать на общем или рабочем окружении.

`python tests/pgadmin_browser.py` — только для одноразового стенда с `.env`, содержащим простые незаключённые в кавычки значения. Установка: `pip install playwright==1.56.0`, `python -m playwright install --with-deps chromium`. Проверяет login через префикс, загрузку JS/CSS и отображение обеих подключённых БД. Снимки в игнорируемом `test-results/`, в CI они публикуются как артефакт.

GitHub Actions выполняет эти проверки на Ubuntu 24.04 с Docker. Просмотр результатов не требует локального Docker. CI в конце удаляет **свои** одноразовые volumes. Не копируйте шаг cleanup на стенд с нужными данными.
